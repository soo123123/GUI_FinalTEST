## 유니티 엔진 기본 개념
**유니티 엔진은 프레임 기반 게임 루프를 반복하며 게임을 실행한다.**
- 프레임 기반 게임 루프: "화면을 그릴 때마다 게임 로직을 한 번씩 실행하는 구조"
- 1프레임: 화면이 한 번 새로 그려지는 단위
₩₩₩ //1프레임 개념적 코드
while (게임 실행 중)
{
    입력 처리
    Update 실행
    물리 처리
    화면 그리기
}
₩₩₩

**유니티는 활성화된 컴포넌트에 붙은 스크립트에서 자동호출 함수를 호출한다.**
- Update() //프레임 마다 무조건 호출
- FixedUpdate() //프레임 기준이 아닌 고정 시간 간격
- LateUpdate() //Update 끝난 뒤 항상 실행

**유니티는 매 프레임마다 게임 루프에서 활성 컴포넌트의 Update()를 호출한다.**
- 함수 호출 시 실행 정보, 매개변수, 지역 변수로 구성된 스택 프레임 생성됨.
- 매 프레임 유니티 엔진이 Update() 호출함.

**유니티 inspector창은 게임 오브젝트와 컴포넌트로 구성되어 있다.**
- 창 자체는 게임 오브젝트
- 안에 붙어있는 옵션은 컴포넌트
₩₩₩
Player 게임오브젝트
 └── Player 스크립트 (컴포넌트)
      └── hpBar 변수(참조변수)
            ↓ 참조
Player_HP 게임오브젝트
 └── Image 컴포넌트
